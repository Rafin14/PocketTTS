# Security policy

Please report security and privacy issues privately through GitHub's private
vulnerability reporting feature when it is enabled for this repository. Do not
open a public issue containing credentials, private voice samples, personal
data, or a working exploit.

If private reporting is unavailable, open an issue requesting a private contact
channel without disclosing vulnerability details or sensitive information.

This experimental project does not currently promise long-term security support
for old releases. Reproduce reports against the latest commit when possible and
include the Android version, device architecture, app version, and minimal logs.
