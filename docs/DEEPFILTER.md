# Offline noise reduction

DeepFilterNet3 reduces background noise in a recorded, imported or video-extracted
voice reference. It runs after trimming and before saving, entirely on device.
The model is packaged with the app and is not downloaded at runtime.

It does not process Reader speech, Android system TTS or microphone input in real
time. It is not transcription, voice activity detection or speaker separation.

## Use enhancement

1. Record or import audio and select a 3–30-second section.
2. Apply the trim or continue with a valid full sample.
3. Compare **Before** and **After** using their waveforms and preview controls.
4. Choose the unenhanced or enhanced reference, then save.

Enhanced audio is selected by default when processing succeeds. If enhancement
fails, the unenhanced sample remains available and Retry is offered.
Re-recording replaces an unsaved take; closing the workflow discards unsaved
temporary files. Saved originals are not overwritten.

Saved custom voices can use the same workflow through **Edit audio**.
See [voice management](PLAYBACK_AND_VOICE_EDITING.md) and
[trimming](TRIMMING_AND_SPEED.md).

## Audio processing

Selected audio is normalized to mono PCM16 at 24 kHz, resampled to 48 kHz for
DeepFilterNet3 DSP/model inference, then resampled to 24 kHz without changing
sample count. The enhanced result is a separate WAV.

The DSP performs STFT, Vorbis windowing, ERB features, normalization, complex deep
filtering and overlap-add. The bounded 3–30-second clip is processed as one
sequence. CPU inference uses two intra-op threads and one inter-op thread.
Session ownership and release are serialized behind native work to prevent
canceled workflows from releasing a model still in use.

The app reuses ONNX Runtime 1.20.0. No separate inference framework, network
service or real-time recording filter is needed. Extracted model files are
checksum-validated and repaired from the bundled asset when necessary.

Source WAV limits are 256 MiB and 30 minutes; these are separate from the
enhancement window. Supported formats and conversion are documented in
[Trimming and speed](TRIMMING_AND_SPEED.md).

## Model provenance

The graph is from
[soniqo/DeepFilterNet3-ONNX](https://huggingface.co/soniqo/DeepFilterNet3-ONNX),
revision `63d8ba442ba900143c468b798e94a04009b2f0c9`.

- Asset: `app/src/main/assets/deepfilter/deepfilter.onnx`.
- FP32, opset 17; 8,608,859 bytes.
- SHA-256: `e1157049059434ae0d5857e32c812abea227b975e946b2eb64d001abbce156d3`.
- Inputs: `feat_erb [1,1,T,32]`, `feat_spec [1,2,T,96]`.
- Outputs: `erb_mask [1,1,T,32]`, `df_coefs [1,5,T,96,2]`.

DSP and the offline band-limited resampler are adapted from
[soniqo/speech-core](https://github.com/soniqo/speech-core),
revision `f0050757a7d7d24c60b17e60016989ecd07a491d`.
Only the required offline DSP/resampling components are used. KissFFT supplies
the real/complex FFT implementation.

`app/src/main/cpp/deepfilter/denoiser.h` provides a dedicated ONNX session;
`jni.cpp` exposes create/process/release. Auxiliary tables are generated by the
pinned DSP implementation, so an additional auxiliary binary is not required.

The graph is MIT-licensed, adapted speech-core sources are Apache-2.0, and
KissFFT is BSD-3-Clause. Original notices are retained in the source tree and
bundled beside the graph in `NOTICES.txt`.
See [third-party notices](../THIRD_PARTY_NOTICES.md).

## Testing and limitations

`DeepFilterTest` exercises real bundled-model inference, repeated processing,
release/reopen, output shape/finiteness and original preservation.
`VoiceWorkflowTest` and `PlaybackVoiceEditingTest` exercise review, saving and
editing through the UI. Run device tests using [Building and testing](BUILDING.md).

Noise reduction cannot reliably remove music, reverberation or another speaker.
Compare real noisy speech and cloning quality on ARM64 hardware. Automated audio
shape and lifecycle checks do not establish perceptual quality or thermal
performance for every device and recording.
