# PocketTTS screenshots

This gallery contains actual PocketTTS 4.0 application captures from an Android 16 emulator at 1080 × 2400, using Dark appearance and default text size.

Screens cover Reader, Voices, Add Voice, recording, video extraction, trimming, enhancement review, Settings and About. Demonstration audio uses an attributed Alba reference or synthetic material; no private recordings or documents are included.

The gallery illustrates the interface. Device performance, native ARM64 synthesis and microphone quality depend on hardware.
